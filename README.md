# OctoAcme Project Management Docs

This repository centralizes the core project management processes used by OctoAcme. It gives teams a shared, discoverable source of truth for how work is initiated, planned, executed, released, and improved over time.

## Process Summary

OctoAcme follows a lightweight project lifecycle to keep work aligned and predictable:

- Initiation: validate the problem, align stakeholders, and decide whether to proceed.
- Planning: define scope, milestones, backlog, ownership, and dependencies.
- Execution & tracking: run delivery in iterations, track progress, and escalate blockers.
- Risk & communication: document risks, dependencies, and stakeholder updates.
- Release & deployment: ship changes safely with verification, rollback plans, and release notes.
- Retrospective & continuous improvement: capture lessons learned and turn them into action.

## Why this matters

These process docs help the team align on roles, milestones, risks, delivery rituals, and continuous improvement across the project lifecycle. They reduce ambiguity, improve onboarding, and support consistent execution across teams and projects.

## Recommended usage

1. Start with the [Project Management Overview](docs/octoacme-project-management-overview.md) for context.
2. Use the [Project Initiation Guide](docs/octoacme-project-initiation.md) when a new project or idea is being considered.
3. Move into planning with the [Project Planning](docs/octoacme-project-planning.md) guidance.
4. Use the execution, risk, and release docs throughout delivery and deployment.
5. Close the loop with the retrospective guide to capture improvements.
